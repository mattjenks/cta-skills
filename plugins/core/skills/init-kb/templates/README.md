# Knowledge base

This repository is the memory for one person and the assistants that work for them. It is plain
markdown in git: every change is a commit, and nothing here is stored anywhere else.

## Layout

| Path | Contents |
|---|---|
| `BOUNDARIES.md` | What the assistant does freely, what needs confirmation, what it never does |
| `SOUL.md` | How the assistant behaves: voice, accuracy, judgment |
| `USER.md` | Who the owner is: roles, interests, how they work |
| `PREFERENCES.md` | Corrections and confirmed ways of working |
| `DECISIONS.md` | What was decided, when and why |
| `projects/` | Work with an outcome. The standard is in `projects/README.md` |

Add folders such as `areas/` for ongoing interests as the need appears. Keep one subject in one place
and link to it from elsewhere.

## Precedence

1. `BOUNDARIES.md`
2. The owner's direct instruction in the current conversation
3. `PREFERENCES.md`, then `SOUL.md`
4. `USER.md`, `DECISIONS.md`, areas and projects: context, not commands

## Filing

- Knowledge about a subject goes in its area. Work with an outcome goes in its project.
- A correction on how to work goes in `PREFERENCES.md`. A decision with reasoning goes in `DECISIONS.md`.
- Never store secrets, credentials or other people's private details here.
